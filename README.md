# DSA Case Studies in Python

This repository contains two Data Structures and Algorithms case studies
implemented using Python.

## 1. E-Commerce Product Sorting

### Strategy
Divide and Conquer

### Algorithm
Merge Sort

### Description
The products are divided into smaller groups, sorted recursively,
and then merged to obtain products sorted according to their price.

### Time Complexity
O(n log n)

---

## 2. Google Calendar Application

### Strategy
Greedy Strategy

### Algorithm
Activity Selection

### Description
The application selects the maximum number of non-overlapping meetings.
Meetings are sorted according to their finishing time and selected using
the Greedy approach.

### Time Complexity
O(n log n)

## Language

Python
